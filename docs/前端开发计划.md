# 前端可视化开发计划（frontend/current）

> 状态：**已评审通过，进入开发**
> 技术栈确认：Vue3 全家桶 + Naive UI + FastAPI；支持亮暗主题切换；Neo4j 本地可用。
> 最后更新：2026-08-23

---

## 1. 背景与目标

将 `src/current` 管线产出的真实数据（供应链图、KMV/混合标签、模型评测指标）以 Web
界面呈现，替换 legacy 前端「fetch 静态 Excel」的脱节做法。

核心诉求：

1. Vue3 全家桶，适配电脑与手机；
2. 无侧边栏，整体设计大气；
3. 供应链图支持按年份切换，优先使用 Neovis.js（Neo4j 官方页面插件）；
4. 组件高复用，基于 Naive UI，不重复造轮子。

## 2. Legacy 界面盘点（结论）

|---|---|---|

### 5.1 可迁移配置（`.env` + 启动自动同步）

Neo4j 不再硬编码连接信息，改为从根目录 `.env` 读取（`config.get_neo4j_config()`）：

```ini
NEO4J_URI=bolt://localhost:7687
NEO4J_USER=neo4j
NEO4J_PASSWORD=<你的密码>
NEO4J_DATABASE=neo4j   # 可选
```

- **`server` 每次启动自动同步**：`server/services/neo4j_sync.py::sync_neo4j()` 在 lifespan 后台线程执行，
  把 `processed/{nodes,edges,labels}.parquet` 的供应链图写入 Neo4j（节点 MERGE、关系先删后建，幂等）；
  未配置或不可达时打印日志并优雅跳过，不影响 parquet 数据服务。
- 手动重建/校验：`.venv\Scripts\python.exe scripts/export_neo4j.py [--wipe]`。
- 用户电脑上只要装了 Neo4j、在 `.env` 配好账号密码，起 server 即完成仓库建立与数据同步，无需额外步骤。

## 6. 页面架构（顶部导航，无侧栏）

```
┌──────────────────────────────────────────────────┐
│ ◆ 供应链风险智能评估     总览 图谱 风险 企业 对比  🌓 │ ← 玻璃拟态顶栏（移动端折叠）
└──────────────────────────────────────────────────┘
```

1. **总览 Dashboard**：大字号 KPI 卡（公司数/边数/平均违约概率/R²·AUC）；评级环形图 +
   概率直方图 + 训练损失曲线 + 预测散点；高风险 Top10 榜。
2. **供应链图谱**：年份滑块（2001–2025）全屏画布；Neovis 主模式（Cypher 按年查询），
   ECharts 兜底模式；节点点击 Drawer 展示评级/概率/上下游；顶栏搜索直达节点。
3. **风险评测**：指标卡（R²(prob)/R²(logit)/Spearman/IC/AUC/KS）；实际vs预测散点（45°线、
   评级着色）；TGC vs KMV 对照表（行业筛选 + 分页 + 评级 Tag + 概率进度条）；run 切换器。
4. **企业分析**：搜索公司 → 概览卡（评级/概率/ST 标记）；10 特征趋势折线；违约概率历史
   曲线（标签 vs 预测双线）；该公司为中心的子图（复用图谱组件）。
5. **方案对比**：experiments_log 横向对比表，行选中联动详情。


**API 草案**：

| 接口 | 说明 |
|---|---|
| `GET /api/meta` | 年份列表、run 列表、数据规模统计 |
| `GET /api/graph/years` | 有边的年份及各年边数 |
| `GET /api/graph/{year}` | 该年 `{nodes, links}`（ECharts 兜底模式） |
| `GET /api/model/runs` | experiments_log 台账 |
| `GET /api/model/metrics?run=` | metrics.json 内容 |
| `GET /api/model/eval-log?run=` | eval_log.csv |
| `GET /api/predictions/test?run=&rating=&industry=` | test_predictions 过滤 |
| `GET /api/predictions/future?run=` | 2025 榜单 |
| `GET /api/company/{symbol}` | 详情：特征序列/标签序列/预测/上下游 |
| `GET /api/company/search?q=` | 代码/名称模糊搜索 |

Neovis 直连 Bolt 的查询由前端发起（`MATCH (a:Company)-[r:SUPPLIES|SELLS_TO {year:$y}]->(b:Company) ...`），
连接配置存 localStorage。

## 10.1 部署方式

**开发模式**（前后端分离）：
```bash
# 后端 API
bash server/api.sh start            # 127.0.0.1:8000
# 前端（vite dev server，含 /api 代理）
cd frontend/current && npm run dev  # http://localhost:5173
```

**生产模式**（单进程，前端 build 产物由 FastAPI 托管）：
```bash
cd frontend/current && npm run build   # 生成 dist/
bash server/api.sh start               # 打开 http://127.0.0.1:8000 即可
```

## 11. 风险与备注

1. Enterprise 试用 30 天到期风险（见 §5），导入脚本保持 Community 兼容；
2. 图谱渲染已统一为 ECharts（neovis.js 因边 id 冲突等缺陷弃用）；Neo4j 仅作为数据落库/校验，
   前端经 FastAPI `/api/graph/{year}` 读 parquet，不直连 7687；
3. parquet 读取在 FastAPI 进程内做 mtime 缓存，重训后无需重启服务；
4. 前后端分离开发，生产可将 build 产物挂到 FastAPI `StaticFiles` 单进程部署（已实现于 §10.1）。
