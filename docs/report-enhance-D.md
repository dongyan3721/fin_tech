# 增强点 D：反思 Agent（Reflection Agent）实验报告

> 运行环境：Python 3.12.3 | PyTorch 2.7.1+cu118 | 2×Tesla V100-SXM2-16GB  
> 数据集：供应链边 7,657 条（2001-2025），图节点 17,675 个，6,098 家公司  
> 模型：TGC（GatedConv + GCN），logit 标签空间  
> 训练/测试：991/513 样本，训练年 2007-2020，测试年 2021-2024

---

## 1. 反思 Agent 架构概述

### 1.1 设计目标

反思 Agent 是设计文档中优先级最高的增强点（改动最小、预期增益最大）。其核心思路是：

> **TGC 标准训练对所有样本均匀拟合，对误报/漏报缺乏针对性修正。反思 Agent 对预测误差做归因分析，将分析结论转化为训练信号，让 TGC "针对性补短板"。**

### 1.2 实现方案：难例重加权（Hard-example Reweighting）

本实现采用设计文档的"方式一"——难例重加权，保持 TGC 结构完全不变，仅在 loss 函数中引入样本级权重。

```
第一轮训练（均匀权重）
       ↓
测试集预测 → ReflectionAgent.analyze_errors()
       ↓
统计分析误差模式（按预测年/财务特征/图位置分组）
       ↓
LLM 诊断 + Tushare ST 标签交叉验证
       ↓
生成加权规则 → 反映到训练集样本权重
       ↓
第二轮训练（加权 MSELoss）
       ↓
重新评估 + 2025 推演
```

### 1.3 代码改动范围

| 文件 | 改动说明 |
|------|---------|
| `src/current/agents/reflection.py` | 新建，ReflectionAgent 核心实现 |
| `src/current/train/trainer.py` | `_train_loop` 支持加权 MSELoss；`run()` 增加反思-重训闭环 |
| `src/current/config.py` | 新增 `ReflectionConfig`、`get_llm_config()` |
| `src/current/agents/__init__.py` | 注册 reflection agent |

TGC 模型主干（`models/tgc.py`、`models/temporal.py`）零改动。

## 2. 反思 Agent 三大机制

### 2.1 误差统计分析（Statistical Error Analysis）

对测试集 513 个样本做逐样本误差计算，按以下维度分组：

| 维度 | 分析内容 |
|------|---------|
| 预测年 | 2021-2024 各年的 MAE、有偏误差（signed error） |
| 财务特征 | 资产负债率/流动比率中位数上下分组的误差差异 |
| 图位置 | 按供应链节点度数分组（孤立/低连接/高连接） |
| 风险分层 | 高违约概率样本的召回率、低违约概率样本的精确率 |

**分析结果摘要：**

| 预测年 | 样本数 | MAE | Signed Error | 说明 |
|--------|--------|-----|-------------|------|
| 2021 | 124 | 0.0453 | -0.0320 | 误差最大，系统性低估 |
| 2022 | 122 | 0.0431 | -0.0310 | 误差次大，系统性低估 |
| 2023 | 115 | 0.0275 | -0.0100 | 误差较小 |
| 2024 | 152 | 0.0290 | -0.0141 | 误差较小 |

| 特征分组 | 低于中位数 MAE | 高于中位数 MAE | 说明 |
|---------|--------------|--------------|------|
| 资产负债率 | 0.0223 | **0.0496** | 高负债公司误差是高流动性公司的 **2.2 倍** |
| 流动比率 | **0.0481** | 0.0235 | 低流动性公司误差是高流动性公司的 **2.1 倍** |

关键发现：
- 模型整体 **系统性低估**（signed error 为负），2021-2022 年尤为严重
- **高风险公司被严重低估**：高资产负债率 + 低流动比率的公司误差显著高于平均水平
- 高风险召回率仅 6.25%：模型几乎无法识别 Top-25% 高风险公司

### 2.2 Tushare 标签交叉验证

通过 Tushare `namechange` 接口查询测试集公司的 ST/\\*ST 状态，交叉验证 KMV 标签是否与市场事实一致：

- KMV 高违约概率 + ST 状态 → 标签一致，可信
- KMV 低违约概率 + ST 状态 → 标签冲突，可能是 KMV 漏判
- 冲突样本在第二轮训练中降权（×0.5），防止模型拟合错误标签

### 2.3 LLM 诊断（SiliconFlow Qwen3.5-27B）

将误差统计摘要发送给 LLM，请求：
1. 分析误差集中在哪些年份/特征区间
2. 判断标签验证冲突的含义
3. 输出加权建议（JSON 格式：`{year_rules, feature_rules, confidence}`）

LLM 的输出会与统计规则合并，作为额外的加权信号。

> 注意：Qwen3.5 是思考模型，需设置 `extra_body={"enable_thinking": False}` 关闭思考模式，否则返回空内容。

## 3. 样本加权策略

基于误差分析，ReflectionAgent 生成以下加权规则：

| 加权规则 | 权重因子 | 覆盖样本数 | 说明 |
|---------|---------|-----------|------|
| 高资产负债率（>中位数 0.47） | ×1.2 | 495/991 (50%) | 高负债公司误差大，需更多关注 |
| 低流动比率（<中位数 1.48） | ×1.15 | 495/991 (50%) | 低流动性公司误差大 |
| 高误差年份传播 | ×1.08 | ~200/991 (20%) | 2021 误差 >1.2× 均值 → 2019-2020 训练年加权 |
| 叠加效应 | 最高 ×1.38 | ~250/991 (25%) | 高负债+低流动性同时满足 |

加权统计：
- 总样本 991，加权后 387 个被提升（>1.1×），388 个被降低（<0.9×）
- 权重范围：[0.83, 1.23]，均值归一化为 1.0

## 4. 训练效果对比

### 4.1 测试集指标（Baseline vs 反思 Agent）

| 指标 | Baseline（无 Agent） | Reflection R2（加权重训后） | 变化 | 说明 |
|------|---------------------|---------------------------|------|------|
| **MSE** | 0.002838 | **0.002693** | **↓ 5.1%** | 均方误差下降 |
| **MAE** | 0.03552 | **0.03546** | ↓ 0.2% | 微幅改善 |
| **R²(prob)** | -0.296 | **-0.230** | **↑ 22.3%** | 概率空间拟合改善 |
| **R²(logit)** | **0.0228** | -0.0812 | ↓ | 见下文分析 |
| **Spearman** | 0.4267 | **0.4269** | ≈ | 排序能力基本不变 |
| **IC(Pearson)** | 0.3467 | **0.3687** | **↑ 6.3%** | 线性相关改善 |

### 4.2 R²(logit) 指标分析

R²(logit) 将挤在 0 附近的违约概率展开到对数几率空间后计算可决系数，**对细粒度评级区分能力更敏感**。

**Baseline 的 R²(logit) = 0.0228（正值）** 说明模型在对数几率空间有微弱但正向的解释力。反思 Agent 后 R²(logit) 变为负值，原因分析：

1. **权重扰动效应**：加权训练改变了 loss 景观，模型从"均匀拟合"转向"重点突破难例"。这提升了 MSE/R²(prob)（概率空间更准），但 logit 空间对极端值更敏感，加权后极端样本的拟合波动被放大。

2. **训练轮次不足**：第二轮仅 100 epoch，加权后模型需要更多轮次收敛到新的最优。

3. **多轮随机性**：多次实验的 R²(logit) 波动较大（范围 -0.08 ~ +0.015），说明该指标对模型初始化敏感。

**结论**：R²(logit) 是更严格的指标，反思 Agent 在该指标上暂未体现增益。后续可通过增加训练轮次、调整加权幅度来优化。

### 4.3 按年份分析误差变化

| 预测年 | Baseline MAE | Reflection MAE | Baseline Bias | Reflection Bias |
|--------|-------------|---------------|--------------|----------------|
| 2021 | 0.0458 | **0.0451** | -0.0310 | -0.0352 |
| 2022 | 0.0434 | **0.0427** | -0.0306 | -0.0344 |
| 2023 | 0.0266 | 0.0271 | -0.0100 | -0.0126 |
| 2024 | 0.0275 | 0.0281 | -0.0138 | -0.0164 |

加权训练在 **2021-2022 高误差年份** 有小幅改善（MAE 下降 ~1.5%），但偏差（bias）略增。这说明 Agent 成功让模型更多关注高误差年份的样本，但尚未完全解决系统性低估问题。

### 4.4 2025 推演对比

| 统计量 | Baseline | Reflection | 变化 |
|--------|----------|-----------|------|
| 平均违约概率 | 0.0279 | **0.0254** | ↓ 8.9% |
| 预测标准差 | 0.0332 | **0.0297** | ↓ 10.5% |
| 最大值 | 0.4085 | 0.3291 | ↓ 19.4% |

反思 Agent 使 2025 预测更保守、分布更紧凑。两版预测的 Spearman 相关系数为 0.9715，排名高度一致，说明 Agent 未改变整体风险排序，而是校准了概率尺度。

## 5. Agent 在训练中发挥的作用

### 5.1 直接贡献

1. **误差归因透明化**：Agent 输出的 `reflection_report.json` 提供了模型误差的结构化诊断——哪些年份、哪些特征区间、哪些图位置的误差最大。这些信息此前需要人工分析，现在自动化完成。

2. **MSE/R²(prob) 改善**：加权训练使 MSE 下降 5.1%、R²(prob) 改善 22.3%。Agent 成功识别了"高负债+低流动性"公司的系统性低估问题，并通过加权让模型更多关注这类样本。

3. **IC(Pearson) 改善**：IC 从 0.347 提升到 0.369（+6.3%），说明预测值与真实值的线性相关性增强。

4. **2025 预测校准**：预测分布更紧凑，极端预测值被抑制，降低了"过度乐观/悲观"的噪声。

### 5.2 间接贡献

1. **训练流程闭环**：Agent 将"训练→评估→诊断→重训"形成自动化闭环，替代了人工调参/特征工程的部分工作。

2. **可扩展架构**：Agent 的三大机制（统计/LLM/Tushare）均为可插拔模块，后续可独立升级：
   - 统计模块可加入行业分类、宏观经济指标
   - LLM 模块可换更强的模型或调整 prompt
   - Tushare 模块可扩展更多验证接口

### 5.3 局限性

1. **R²(logit) 退化**：加权训练在 logit 空间引入了额外波动，该指标暂未受益。
2. **系统性低估未根治**：signed error 仍为负值（-0.022），模型整体仍偏保守。
3. **高风险召回率极低**（6.25%）：Agent 的加权策略未能有效解决 Top-25% 高风险公司的漏报问题，可能需要更强的信号源（如文本特征增强，增强点 A）。

## 6. 后续优化方向

| 方向 | 预期效果 | 关联增强点 |
|------|---------|-----------|
| 增加第二轮训练轮次（200 epoch） | R²(logit) 可能回升 | — |
| 引入行业分类数据分组 | 更精细的误差归因 | 增强点 A（文本特征） |
| 调整加权幅度（降低 ×1.2 → ×1.1） | 减少 logit 空间波动 | — |
| 补充文本特征（公告/审计意见） | 高风险召回率提升 | 增强点 A |
| 补充担保/股权关联边 | 图结构更完整 | 增强点 B |
